# Tela de Login e Cadastro com Bootstrap

## Descricao

Projeto de uma tela de login e cadastro interativa e responsiva, desenvolvida com Bootstrap 5 e JavaScript puro. A aplicacao permite alternar entre os modos de autenticacao e registro, validar campos de entrada e persistir as credenciais localmente no navegador atraves do LocalStorage.

Atividade desenvolvida por Isabela de Oliveira.

## Funcionalidades

- Alternancia dinamica entre os formularios de Login e Cadastro sem recarregar a pagina
- Ocultacao e exibicao de senha com alternancia de icone
- Validacao de formato de e-mail e tamanho minimo de senha
- Cadastro e autenticacao de usuarios salvos via LocalStorage
- Mensagens de feedback em tempo real para sucesso ou erro
- Design responsivo adaptado para dispositivos moveis e desktop

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Como Executar

1. Clone ou baixe os arquivos do repositorio.
2. Abra o arquivo index.html em qualquer navegador web.
